# Experiment 132: Does RAG chunk-size ranking flip with the metric?

## Question and evidence
Does a smaller chunk improve retrieval while a larger chunk improves answers on the same questions? Source: [Aqeel Abbas, Which RAG Chunk Size Is Best?](https://medium.com/illumination/which-rag-chunk-size-is-best-the-answer-flips-depending-on-how-you-score-it-2c3ef424e50c). The accessible preview describes precision versus surrounding context and says the winner changes with the reading budget. The full method/results are paywalled; this is an independent test, not an exact replication. We make directional predictions from that mechanism, not invented numerical effect forecasts.

## Preregistration (before any pilot outcomes)
- H1: 128-token chunks beat 1024-token chunks on both retrieval Recall@5 and MRR@5.
- H2: 1024-token chunks beat 128-token chunks on answer token F1, giving an endpoint ranking reversal. Exact match and a sampled Qwen correctness judge are secondary checks. All four sizes (128, 256, 512, 1024) will be reported; the primary endpoints are fixed to avoid choosing a convenient contrast after seeing results.
- Practical margin: 0.05 absolute for each primary metric. Five points means one more useful result per 20 questions and is large enough to justify changing an ingestion pipeline. This is a utility threshold, not a predicted effect.
- Pilot: 300 questions from HF `rajpurkar/squad`, validation, seed 132. Group all validation paragraphs into documents by article title. Sample one question per source paragraph to reduce repeated-context dependence. Corpus contains all validation articles, not just the questions selected.
- Confirmation: 600 questions from HF `hotpotqa/hotpot_qa`, `distractor`, validation, seed 132. Corpus is the union of title-deduplicated context documents in those 600 examples, searched globally, not an oracle per-question context. Both supporting documents are relevant. All question IDs and document texts are saved before retrieval.
- Pilot and confirmation use different datasets; no pilot question appears in confirmation. Pilot guides interpretation and checks feasibility, but does not change the fixed hypotheses, contrast, or confirmation sample size.
- Retrieval Recall@5 is the fraction of gold source documents represented among the five retrieved chunks; MRR@5 is the reciprocal rank of the first chunk from a relevant document (zero if absent). These are document-relevance metrics, not answer-span containment. Multiple chunks from a document can consume multiple slots. SQuAD has one gold document; HotpotQA normally has two. Gold document labels do not imply that every chunk contains the answer.
- Chunking uses Qwen3's tokenizer, nonoverlapping fixed windows, never across documents. Embeddings: `Qwen/Qwen3-Embedding-0.6B`, last-token pooling, normalized vectors, instruction for queries only, FAISS inner-product exact search. Full chunks are embedded, with no hidden truncation.
- Answers: `Qwen/Qwen3-4B`, greedy decoding, thinking disabled, maximum 64 new tokens, identical prompt, top five chunks in score order, no reranking, no input truncation. Fixed top-k intentionally means up to 8x more context tokens for 1024 than 128. This tests that operating policy, not equal token budgets. Record actual input and output token counts per answer. No paid APIs.
- Answer scoring: standard lowercase/punctuation/article/whitespace normalization, maximum token F1 and exact match over gold aliases. No answer tuning after evaluation. Judge: first 60 shuffled questions per dataset, all four sizes, same Qwen model, separate reference-based prompt, binary correctness; compare with F1 >=0.5 and exact match. Judge is a diagnostic, not independent human validation.
- Statistics: paired question bootstrap, seed 132, 10,000 resamples, ordinary 95% percentile CIs for reported metrics/differences. For the three primary directional contrasts also use 98.333% intervals (Bonferroni family coverage >=95%). Primary differences are small-minus-large Recall and MRR, large-minus-small F1.
- Decision on confirmation only: **PROVEN** if every primary simultaneous lower bound is >0 and every point difference is >=0.05; **DISPROVEN** if any simultaneous upper bound is <0 (a required direction reverses); otherwise **INCONCLUSIVE**. A miss of the five-point threshold alone is not proof of the opposite. A global four-size winner reversal is descriptive and does not replace this rule.
- Sample-size rationale: 600 paired questions resolves medium effects, not sub-point differences. For a paired SD of 0.5, an ordinary 95% half-width is about four points and simultaneous half-width about five points. Pilot SDs and resulting precision will be reported. No claim of sensitivity to small effects; question-level CIs are conditional on this corpus and do not measure training/model-seed uncertainty.
