# RAG chunk size and evaluation metrics

Three independent studies of how chunk size affects retrieval and answer quality. Each folder contains its protocol, code, saved results, figures, and verdict.

- [HotpotQA: chunk-size rankings across metrics](original-run/) (128 vs 1024 tokens, 600 HotpotQA questions) — **INCONCLUSIVE**
- [Fresh multi-hop questions with a fixed evidence budget](chunk-size-multihop-fresh/) (budget-controlled) — **INCONCLUSIVE**
- [MuSiQue: chunk size on multi-hop QA](chunk-size-musique/) — **INCONCLUSIVE**

Large artifacts are available in the [data release](https://github.com/nankris/rag-chunk-size-flip/releases/tag/v1-data); see [RELEASE_ASSETS.md](RELEASE_ASSETS.md).
